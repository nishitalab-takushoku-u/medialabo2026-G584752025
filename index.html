「Webコンテンツ作成について」

本テーマについて

本テーマでは、HTML・CSS・JavaScriptの基礎を学び、Webページの構造・デザイン・動的処理を理解するとともに、各種リファレンスを活用しながら、画像や動画を含む簡単なWebページを作成できる力を身に付ける。

プロジェクト課題について

NHKの番組表についてWWWのサーバへ検索し、検索結果を表示するページです。2022年3月4日の実際の番組表情報です。検索できるのはこの日だけに制限されます検索キーには、チャンネルとジャンルの2つが指定可能です。結果として表示されるのは以下の内容です。チャンネル（NHK総合１、Eテレ１）、ジャンル（ニュース・報道、スポーツ、情報・ワイドショー等）、番組開始時刻、番組終了時刻、チャンネル、番組名、番組サブタイトル、番組説明文、出演者。

プロジェクト課題で作成したページ： project.html

数当てゲーム

1~10の値が1つランダムに生成されています。ユーザーは生成された値を予想してください。最大で３回まで予想することができます。ユーザーの予想が外れた場合は、ヒントとして予想した値よりも答えが大きいか小さいかを表示します。３回以内に生成された値を当てればユーザーの勝ち、当てられなければ負けです。 第３回で学習したinput要素やbutton要素等をHTMLに設置して作成しました。予想した値や予想した回数に応じたテキストが表示されます。

数当てゲームのページ： kazuate.html

各授業回の学習事項

第１回 WWW と HTML

第1回では、HTMLについて学習した。HTML は Web ページの構造を記述するための書式である。HTMLは要素で作られ、タグで最初と最後を囲んだ部分が要素になる。例えばh1要素は大見出しの要素で、タグで囲まれた内容が見出し文字に設定される。同様に，h2, h3, h4, h5, h6 要素も見出しを意味し、数字が大きいほど「小さい」見出しになる。

演習の成果： 演習1-4:HTMLのさまざまな要素

第２回 CSSによるWebページの装飾

第2回では、CSSについて学習した。CSS は要素の見た目を変更するものなので、前回学習したHTML が最初に与えられて、次にその装飾をする CSS を記述する。CSS を HTML に適用する方法は３通りある。別ファイルで作成した外部スタイルシートをHTMLのhead要素で指定する外部スタイルシート。HTMLのhead 要素の中に style 要素を新たに作って，その中に直接 CSS を記述する内部スタイルシート。CSS のセレクタの部分は書かずに、HTML の body 要素の中で見た目を変更したい要素に，style 属性を直接記述するインラインスタイルの３通りである。

演習の成果： 演習2-3:ウェブブラウザ説明ページの装飾

第３回 JavaScriptの基本

第３回では、JavaScriptについて学習した。Webページ上で複雑な機能を実現するプログラミング言語であるJavaScriptはページの自動更新やアニメーションなど動きのあるページを実現するために使われる。Java と JavaScript は名前が似ているが、別の仕組みを持つ言語である。Javaはコンパイル言語で、プログラムを実行するにはコンパイルしたのち、実行するという２段階の手順を踏む必要がある。一方、JavaScriptはインタプリタ言語で、プログラムは、そのまま１行ずつ読み取りながら実行される。Java におけるコンパイルという一手間がない。

演習の成果： 演習3-6: オブジェクトの参照

第４回 DOM と JavaScript

第4回では，「ボタンを押したらページが変化する」処理を JavaScript プログラムとして記述する方法を学習した。Web コンテンツを表現するデータ構造であるDOM を使用することによって、動きのある Web ページを実現できるようになる．

演習の成果： 演習4-10: 足し算ページ

第５回 イベント処理

第５回ではDOMを使って要素の新規作成・編集・削除について学習した。CSSでクラスの装飾を定義しておき、JavaScript では要素にクラスを追加することでスタイルファイルは複雑になる反面，JavaScript プログラムは「クラスを要素に追加設定する」という比較的簡単なプログラムで実現できるようになる。

演習の成果： 演習5-7 DOMプログラミング(2)

苦心点

苦心した点は２回目以降の検索をした際に前回の検索結果を削除する設定である。グローバル変数を用いてみたが、思った通りに削除できないことが多く、for文でループさせたり、条件文を利用したりを何度も行った。最終的に、“document.querySelectorAll('ul')”を用いて、前回に何個の“ul”が生成されたかを数え、生成された回数“ul”を削除するループを利用して、２回目以降の検索をした際に前回の検索結果を削除するように設定することができた。また、番組開始時刻と番組終了時刻について、サーバから得たデータをそのまま表示すると、一目見ただけでは放送時間が分かりづらく、何時何分〜何時何分のように表示したかったがうまくできなかったため、次にWebコンテンツを作成する機会があればチャレンジしてみたい。

工夫点

検索したチャンネル・ジャンルの番組表が見つからなかった時に“見つかりませんでした”と表示するようにした点。何も表示されない場合と比べると、サーバに検索をかけているかどうかを検索した上で見つからなかったと証明できる。

強調点

プロジェクト課題でNHKの番組表の検索するプログラムを作成したので、NHKの雰囲気のある配色にした。Eテレのイメージカラーの黄緑やNHK総合でよく用いられているオレンジを配色した。また、プロジェクト課題のタイトルに用いた色はそれぞれ“N”、“H”、“K”から始まる色で配色した（navy,honeydew,khaki）。

感想

今回の課題を通して、Webページは見た目だけでなく利用者の使いやすさも重要であることを学んだ。HTMLやCSSの知識を実際に活用することで理解が深まり、今後の学習にも役立てたいと感じた。思った通りに動作しない時はやり切れない気持ちになり、課題を取り組むのも億劫になっていたが、ある程度抱えていた問題が解決し、スムーズに動作するようになると気持ちが軽くなった。また、プロジェクト課題をコツコツ進めておけばよかったと思う。再提出になってしまったし、もっと凝った検索結果の表示もしたい。今更になってCSSでの装飾が楽しいと感じた。もう一度Webコンテンツを作るチャンスがあれば、今回よりも完成度の高いWebコンテンツを時間をかけて作りたい。苦心点で取り上げた２回目以降の検索をした際に前回の検索結果を削除する設定に時間がかかりすぎてしまったのが反省点である。先にCSSでの装飾に取り組んだり、詳しい人に聞きに行くべきであった。しかし、時間をかけて問題を解決するのも辛かっただけではなく、解決できた際の達成感や同じような場面に遭遇した時に対応できた経験は自信に繋がる。これからも難題に恐れず早めの段階から取り組むようにしていきたい。
